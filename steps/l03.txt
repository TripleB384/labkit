--- Step 1 ----------------------------------------
Marcus: "The shell remembers everything you type." Look at your
recent commands.

  $ history | tail -5
  You should see:
    Your last 5 commands, each with a number.
  What each part means:
    cd                          = Change directory (move to another folder)
    ~/linuxlab                  = ~ = your home folder
    history                     = List the commands you typed before
    |                           = pipe: send the output of the left command into the next one
    tail                        = Show the last lines of a file (default 10)
    -5                          = show the last 5 lines

--- Step 4 ----------------------------------------
Finance asks for average revenue per customer. Notice which math
method drops the cents.
  $ echo $((1228 / 12))
  $ echo "scale=2; 1228 / 12" | bc
  You should see:
    102
    102.33
  Why:
    $(( )) drops decimals. bc keeps them.
  What each part means:
    echo                        = Print text
    $((1228 / 12))              = $(( )) = shell math (whole numbers only)
    "scale=2; 1228 / 12"        = bc input: scale=2 = keep 2 decimal places
    |                           = pipe: send the output of the left command into the next one
    bc                          = Calculator that handles decimals

--- Step 5 ----------------------------------------
Make the plan prices look tidy for a quick price sheet.

  You should see:
    Gold       149.00
    Basic       59.50
  Why:
    printf reuses the format for each pair of values.
  What each part means:
    printf
        = Print text with a format (%s text, %6.2f number with 2 decimals,
        \n new line)

--- Step 7 ----------------------------------------
Tired of typing ls -lh? Make a shortcut for it, then remove it.
  $ alias ll='ls -lh'
  $ ll
  $ unalias ll
  You should see:
    ll shows a long listing. After unalias, ll is gone.
  What each part means:
    alias                       = Make a shortcut name for a longer command
    ll='ls -lh'                 = name=command: 'll' will run 'ls -lh
    ll                          = your new shortcut (it runs ls -lh)
    unalias                     = Remove a shortcut

--- Step 8 ----------------------------------------
Marcus explains why his settings vanished last week: he ran a script
instead of sourcing it. See the difference yourself.
  $ echo 'MYVAR=pool' > vars.sh
  $ bash vars.sh
  $ echo "[$MYVAR]"
  $ source vars.sh
  $ echo "[$MYVAR]"
  You should see:
    []
    [pool]
  Why:
    bash runs it in a separate shell, so the variable disappears. source
    runs it in yours.
  What each part means:
    echo                        = Print text
    >                           = save output to a file (overwrites it)
    bash
        = Run the script in a NEW bash shell (its variables vanish when it
        ends)
    source                      = Run a file in YOUR current shell, so its variables stay

--- Step 9 ----------------------------------------
Get to know this server: your home folder, your shell, and where it
looks for commands.
  $ echo $HOME $SHELL
  $ echo $PATH | tr ':' '\n'
  $ cd /tmp
  $ cd -
  You should see:
    Your home and shell, then each PATH folder on its own line. cd - jumps back to ~/linuxlab.
  What each part means:
    echo                        = Print text
    $HOME                       = your home folder
    $SHELL                      = your login shell
    $PATH                       = folders searched for commands
    |                           = pipe: send the output of the left command into the next one
    tr                          = Translate characters: swap the first set for the second
    ':'                         = the characters to replace
    '\n'                        = what they become (\n = new line)
    cd                          = Change directory (move to another folder)
    -                           = go back to the folder you were just in

--- Step 11 ----------------------------------------
Now the real fix. Back up the app config first (Marcus's rule), then
open it in vim.
  $ cp config/app.conf config/app.bak
  $ vim config/app.conf
  You should see:
    The file opens. You're in Normal mode.
  What each part means:
    cp                          = Copy files
    vim                         = vim text editor (i = type, Esc = stop typing, :wq = save and quit)

--- Step 12 ----------------------------------------
In vim: switch debug off, add a timezone line at the bottom, then
save and quit.
  $ :%s/debug=true/debug=false/
  $ G
  $ o
  $ timezone=UTC
    (press Esc)
  $ :wq
  You should see:
    Back at the prompt.
  Why:
    G = go to last line. o = open a new line below and switch to Insert
    mode.
  What each part means:
    :%s/debug=true/debug=false/
        = vim: % = every line, s/old/new/ = substitute
    G                           = jump to the last line
    o                           = open a new line below and start typing
    timezone=UTC                = the text you type
    Esc                         = stop typing (back to Normal mode)
    :wq                         = write (save) and quit

--- Step 13 ----------------------------------------
Prove exactly what you changed, so Marcus can review it.
  $ diff config/app.bak config/app.conf
  You should see:
    < debug=true
    ---
    > debug=false
    plus an added timezone=UTC line
  What each part means:
    diff                        = Show the lines that differ between two files

--- Step 14 ----------------------------------------
Add "fixed debug mode" to your to-do list using nano.
  $ nano todo.txt
  You should see:
    Type a new line, press Ctrl+O then Enter to save, Ctrl+X to exit.
  What each part means:
    nano                        = Simple text editor (Ctrl+O save, Ctrl+X exit)

STUCK?
  * Stuck in vim
      Press Esc a couple of times, type :q! and press Enter. That quits
      without saving.
  * vim: command not found
      Use vi instead, or run: sudo apt install -y vim
  * Ctrl+R shows the wrong command
      Press Ctrl+R again to go further back. Ctrl+G cancels.
  * nano asks 'File Name to Write'
      Just press Enter to keep the same name.
