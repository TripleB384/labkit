LESSON 5: Partitions   (Linux+ objective 1.3)
============================================================
Setup needed first: sudo bash ~/labkit/u1-disks.sh

GOAL: Partition a fake 300 MB disk with MBR, then switch it to GPT.

--- Step 1: Load your fake-disk names. Do this every time you open a new terminal.
  $ source /tmp/disks.env
  $ echo $DISK1
  You should see:
    /dev/loop0 (or another loop number)
  Why: If it prints nothing, run: sudo bash ~/labkit/u1-disks.sh

--- Step 2: See all disks. Spot your real disk vs the fake loop disks.
  $ lsblk
  You should see:
    Your real disk (nvme0n1, xvda, sda or vda) plus loop0–loop4, each 300M. You may also see small snap loop devices; ignore those.
  Why: Never run fdisk on the real disk. Always use $DISK1.

--- Step 3: Check DISK1. It has no partitions yet.
  $ sudo fdisk -l $DISK1
  You should see:
    Disk /dev/loopN: 300 MiB ... and no partition list.

--- Step 4: Create a 100M MBR partition. Type each key, then Enter.
  $ sudo fdisk $DISK1
  $ o
  $ n
  $ p
  $ 1
    (Enter)
  $ +100M
  $ p
  $ w
  You should see:
    'The partition table has been altered.'
  Why: o = new MBR table, n = new, p = primary, 1 = number, Enter = default start, +100M = size, p = preview, w = save.

--- Step 5: Check it.
  $ lsblk $DISK1
  You should see:
    loopN with loopNp1 100M under it.
  Why: No p1? Run: sudo partprobe $DISK1

--- Step 6: Add partition 2 using the rest of the disk.
  $ sudo fdisk $DISK1
  $ n
  $ p
  $ 2
    (Enter)
    (Enter)
  $ w
  You should see:
    loopNp2 about 199M

--- Step 7: Confirm the table type with parted.
  $ sudo parted $DISK1 print
  You should see:
    Partition Table: msdos  (msdos = MBR)

--- Step 8: Put a filesystem on p1 and read its UUID.
  $ sudo mkfs.ext4 -q ${DISK1}p1
  $ sudo blkid ${DISK1}p1
  You should see:
    UUID="..." BLOCK_SIZE="4096" TYPE="ext4"

--- Step 9: Wipe it and make a GPT table with parted in one line.
  $ sudo wipefs -a $DISK1
  $ sudo parted -s $DISK1 mklabel gpt mkpart data ext4 1MiB 150MiB
  $ sudo parted $DISK1 print
  You should see:
    Partition Table: gpt
     1  1049kB  157MB  156MB  data

--- Step 10: Confirm with gdisk.
  $ sudo gdisk -l $DISK1
  You should see:
    GPT: present
    1  2048  307199  149.0 MiB  8300  data

--- Step 11: See the kernel's view of partitions.
  $ cat /proc/partitions
  You should see:
    major minor #blocks name ... includes your loop partitions

STUCK?
  * $DISK1 is empty: Run: source /tmp/disks.env. If that file is missing, run: sudo bash ~/labkit/u1-disks.sh
  * Typed a wrong key in fdisk: Press q and Enter. Nothing is saved until you press w.
  * Partition not showing in lsblk: sudo partprobe $DISK1
  * Device or resource busy: Something is mounted on it. Run sudo umount on it first.
